# V0.6.1 阶段总结

**日期**: 2026-05-23  
**版本**: V0.6.1 Evidence Pack  
**架构**: VACP (Visual-Centric Agentic Desktop Automation with Provenance)  
**定位**: 可信视觉闭环桌面 Agent

---

## 1. 本阶段目标

从 V0.5 坐标式桌面自动化，升级为 V0.6/V0.6.1 可信视觉闭环桌面 Agent。

核心转变：从「能执行」升级为「能证明自己可信地执行过、能审计、能复现」。

---

## 2. 核心技术贡献

| 组件 | 文件 | 说明 |
|------|------|------|
| Screen State Graph | `Planning/ScreenStateGraph.cs` | 动态建图，节点=UI状态，边=动作 |
| Element Grounding Score | `Planning/VacpTraceRecord.cs` | 0-1置信度，视觉元素与目标匹配度 |
| Action Candidate Ranking | `Planning/ActionCandidate.cs` | 多候选动作打分排序 |
| Risk-Aware Action Gate | `Agent/VacpAgent.cs` | L0=L2执行/L1=LLM规划/L2=高风险需审批 |
| Before-After Verification | `Verification/ChangeDetection.cs` | 前后截图对比，验证动作效果 |
| VACP Trace Logger | `Logging/VacpTraceLogger.cs` | 全量操作痕迹记录，审计溯源 |
| OcrService | `Capture/OcrService.cs` | 文字识别 + ocr-click 组合指令 |

## 4. 边界声明

当前证据来自预定义 demo/test set，不宣称泛化意义上的全场景桌面自动化安全。

---

## 5. 版本路线

```
V0.5: 能执行
V0.6: 能可信地执行
V0.6.1: 能证明自己可信地执行过
V0.7: 从成功执行中沉淀技能 ← NEXT
V0.8: 按任务检索技能并安全注入
V0.9: 和 Phoenix-Evo/Hermes 打通经验层
```

---

## 6. 与整体 Agent 体系的定位

```
Hermes / OpenClaw：任务规划层
Phoenix-Evo：经验沉淀与技能进化层
AgentShield：风险门控与审计层
Peekaboo-Win：Windows 视觉执行层
```

Peekaboo-Win 作为桌面感知与执行层，可与上层 Agent 系统无缝集成。
