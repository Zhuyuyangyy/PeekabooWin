# PeekabooWin V0.6 技术规格说明书

> VACP: Vision-Action Closed-loop Planner — 视觉动作闭环规划器

---

## 一、核心定位

从「看图 → GPT 说点哪 → 执行」的传统架构，升级为：

```
看图 → 结构化感知 → 候选动作生成 → 风险评分 → 最优动作选择 → 执行验证 → 失败恢复
```

这不是桌面自动化工具，而是一个 **可信视觉桌面 Agent 系统**。

---

## 三、核心模块

### 3.1 Screen State Graph `(Perception/UiElement.cs)`

```
G_t = (E_t, R_t, S_t)

E_t = 当前屏幕元素集合
R_t = 元素间空间/语义关系
S_t = 页面状态快照
```

元素结构：
```csharp
UiElement { id, type, label, bounding_box, state, role, source, confidence }
ScreenStateGraph { screen_id, elements[], relations[], state }
```

### 3.2 Element Grounding Score `(Perception/ElementGroundingScore.cs)`

```
Score(element) = 0.4 × VisionConfidence
               + 0.2 × TextMatch
               + 0.2 × PositionPrior
               + 0.2 × TypeMatch
```

阈值：score < 0.75 → 不执行，要求重新截图或人工确认

### 3.3 Action Candidate Ranking `(Planning/ActionCandidate.cs)`

```
ActionScore = 0.35 × GoalRelevance
            + 0.25 × ElementGrounding
            + 0.20 × StateProgress
            + 0.10 × SafetyScore
            + 0.10 × HistoricalSuccess
```

### 3.4 Risk-Aware Action Gate `(Safety/ActionRiskGate.cs)`

```
Risk = 0.30 × OperationRisk
     + 0.25 × PageRisk
     + 0.20 × Irreversibility
     + 0.15 × DataSensitivity
     + 0.10 × Uncertainty
```

| 风险区间 | 决策 |
|---------|------|
| < 0.3 | 自动执行 |
| 0.3–0.6 | 人工确认 |
| ≥ 0.6 | 默认阻断 |

高风险页面：bank / 支付 / login / password / admin  
高风险操作：delete / transfer / send / submit  
敏感数据：密码 / 身份证 / 银行卡 / 地址

### 3.5 Before-After Verification `(Verification/BeforeAfterVerifier.cs)`

```
VerificationScore = 0.4 × VisualChange
                   + 0.3 × ExpectedStateMatch
                   + 0.2 × ElementStateChange
                   + 0.1 × ErrorAbsence
```

决策：
- score ≥ 0.6 → Success
- score < 0.6 → Failed → retry once → rescreenshot + replan

### 3.6 Stable Typer `(Input/StableTyper.cs)`

人类输入节奏模拟：30–50ms/字符，防止 Windows 应用因输入缓冲丢失字符。

## 五、验收指标

| 指标 | 含义 | 目标 |
|------|------|------|
| Element Grounding Accuracy | 元素定位正确率 | ≥ 85% |
| Step Success Rate | 单步动作成功率 | ≥ 90% |
| Text Input Integrity | 输入字符完整率 | ≥ 98% |
| False Click Rate | 错点率 | ≤ 5% |
| High-risk Block Rate | 高风险动作拦截率 | 100% |
| Recovery Success Rate | 失败重试/重规划成功率 | ≥ 70% |

## 六、与 V0.5 的区别

| | V0.5 | V0.6 |
|---|---|---|
| 决策方式 | GPT 单次建议 | 多候选排序 + 风险门控 |
| 执行 | 直接执行 | StableTyper + 失败恢复 |
| 验证 | 无 | 前后截图差分验证 |
| 坐标稳定性 | GPT Vision 飘坐标 | Grounding Score 置信门槛 |
| 风险控制 | 无 | Risk-Aware Action Gate |
| 可信度 | 不可信 | 阈值门控 + 100%高风险拦截 |
