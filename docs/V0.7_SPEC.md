# PeekabooWin V0.7 技术规格说明书

> Visual Skill Memory — UI 模式记忆与复用

---

## 一、核心定位

V0.6 的 VACP 每执行一次任务都需要完整的视觉感知 pipeline（截图 → OCR → GPT Vision → 元素定位），对于**重复性任务**效率较低。

V0.7 引入 Visual Skill Memory：将成功执行的 VACP 轨迹（trace）提取为可复用的**视觉技能（Visual Skill）**，下次遇到相似屏幕时可直接重放，跳过昂贵的视觉感知步骤。

---

## 二、核心概念

### Visual Skill（视觉技能）

```csharp
VisualSkill {
    SkillId: string           // 唯一标识，如 "vs_notepad_text_entry"
    Name: string               // 人类可读名称，如 "Notepad Text Entry"
    AppPattern: string          // 目标应用模式，如 "notepad*" / "chrome*"
    ScreenType: string         // 屏幕类型：edit / web / dialog / file-explorer / generic
    RiskLevel: string          // L0(安全) / L1(需确认) / L2(高风险)
    ProcedureSteps: string[]   // 可执行动作序列，如 ["click(320,450)", "type({text})", "click(btn_save)"]
    SuccessRate: float         // 历史成功率（0–1）
    UsageCount: int            // 被使用次数
    TriggerConditions: string[] // 触发条件列表
    CreatedAt: DateTime
}
```

### Skill Memory Loop

```
                    ┌──────────────────────────┐
                    │  User Task Goal           │
                    └────────────┬─────────────┘
                                 ▼
              ┌──────────────────────────────────────┐
              │  Skill Lookup (Before Planning)      │
              │  appPattern + screenType → Retrieve   │
              └────────────┬───────────────────────┘
                           ▼
              ┌─────────────────────┐   Miss   ┌──────────────────┐
              │  Skill Hit?         │─────────→│  Full VACP Pipe  │
              │  successRate≥0.9    │          │  (Screenshot →   │
              │  usageCount≥2      │          │   Vision → Plan) │
              └────────┬────────────┘          └──────────────────┘
                       │ Hit
                       ▼
              ┌──────────────────────────────────────┐
              │  Skill Replay (Skip Vision)          │
              │  ProcedureSteps 直接执行              │
              │  → Before-After Verification         │
              └────────────┬─────────────────────────┘
                           ▼
              ┌──────────────────────────────────────┐
              │  Success?                             │
              │  RecordUsage(true/false)             │
              └──────────────────────────────────────┘
                           │
                           ▼
              ┌──────────────────────────────────────┐
              │  AfterSuccess: Extract & Store       │
              │  VacpTaskTrace → VisualSkill          │
              └──────────────────────────────────────┘
```

## 三、核心模块

### 3.1 VisualSkillStore `(Memory/VisualSkillStore.cs)`

持久化存储，支持 JSON 文件持久化。

```csharp
void Add(VisualSkill skill)     // 添加或更新技能
VisualSkill? Get(string id)     // 按 ID 查询
IReadOnlyList<VisualSkill> GetAll()  // 列出所有技能
void Delete(string id)          // 删除技能
```

存储路径：`~/.peekaboo/skills.json`（跨 session 持久化）

### 3.2 VisualSkillExtractor `(Memory/VisualSkillExtractor.cs)`

将 VacpTaskTrace 转换为 VisualSkill。

```csharp
// 输入：成功执行后的 trace
// 输出：可复用的 VisualSkill
VisualSkill? Extract(VacpTaskTrace trace)
```

提取策略：
- 目标应用名 → AppPattern
- 页面结构特征 → ScreenType
- 动作序列 → ProcedureSteps
- 历史成功率 → SuccessRate

### 3.3 VisualSkillRetriever `(Memory/VisualSkillRetriever.cs)`

检索最匹配的技能。

```csharp
// 按 appPattern + screenType 检索
VisualSkill? Retrieve(string appPattern, string screenType, double minConfidence = 0.75)

// 检索 Top-K 最匹配技能
List<(VisualSkill skill, double confidence)> Rank(string appPattern, string screenType, int top = 5)
```

匹配算法：
- AppPattern 通配符匹配（`*notepad*` / `*chrome*`）
- ScreenType 精确匹配
- 综合置信度 = SuccessRate × log(UsageCount + 1) / log(10)

### 3.4 VacpPlannerWithSkills `(Agent/VacpPlannerWithSkills.cs)`

在 VacpPlanner 基础上集成 Skill Memory。

```csharp
// Plan 之前：先查技能库
var match = _skills.BeforePlanning(appPattern, screenType);
if (match.CanSkipVision) {
    return SkillPlanResult;  // 跳过 VACP，直接用技能
}

// Plan 之后：成功则提取并存储技能
if (vacpResult.Success) {
    _skills.AfterSuccess(taskTrace);
}
```

### 3.5 VacpSkillIntegration `(Agent/VacpSkillIntegration.cs)`

封装 BeforePlanning / AfterSuccess 逻辑，供 VacpPlannerWithSkills 调用。

## 四、CLI 命令

```bash
# 列出所有已提取的视觉技能
peekaboo-win skill-list

# 回放指定技能（可选：指定目标窗口）
peekaboo-win skill-replay --id vs_notepad_edit --window notepad

# 写入预置演示技能（用于 demo / 测试）
peekaboo-win skill-seed
```

## 五、验收指标

| 指标 | 含义 | 目标 |
|------|------|------|
| Skill Extraction Rate | 成功执行的 VACP 轨迹被提取为技能的比例 | ≥ 80% |
| Skill Hit Rate | 技能查找命中的比例（相同任务的第二次执行） | ≥ 70% |
| Skill Replay Success Rate | 技能回放成功率 | ≥ 90% |
| False Skill Application | 错误应用技能的比例 | ≤ 5% |
| Speedup Ratio | 技能命中时 vs 完整 VACP 的时间比 | ≥ 3x faster |

---

## 六、与 V0.6 的区别

| | V0.6 | V0.7 |
|---|---|---|
| 重复任务 | 每次重新视觉感知 | 第二次起跳过 Vision，直接回放 |
| 记忆 | 无状态，每次独立执行 | VisualSkillStore 持久化 |
| 执行路径 | 100% VACP pipeline | Skill Hit → 跳过 pipeline |
| 适用场景 | 一次性/探索性任务 | 重复性/标准化任务 |
| 效率 | O(Vision) 每次 | O(1) 当 skill hit |
