# PeekabooWin V0.7 Release Note

`peekaboo-win-v0.7`

## Core Contribution
Visual Skill Memory: a persistent skill layer enabling reusable desktop automation experience.

## Delivered Capabilities
- `skill-list` — list all stored visual skills
- `skill-seed` — seed demo visual skills
- VisualSkillStore — JSON persistence at `~/.peekaboo/skills.json`
- VisualSkillExtractor — extract skills from successful VACP traces
- VisualSkillRetriever — retrieve skills by app pattern + screen type
- Demo7 evidence pack
