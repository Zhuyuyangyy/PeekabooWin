# PeekabooWin V0.8 Release Note

**Version:** peekaboo-win-v0.8
**Date:** 2026-05-25
**Core:** Skill-Guided Execution — active retrieval guides VACP planning

---

## What's New in V0.8

V0.8 transitions from V0.7's **skill short-circuit** (skip VACP on high-confidence hit) to **skill-guided execution** (skill influences VACP ranking without bypassing it).

### New CLI Commands

| Command | Description |
|---------|-------------|
| `skill-list` | List all stored visual skills |
| `skill-replay` | Replay a stored skill's procedure |
| `skill-seed` | Initialize with pre-built seed skills |
| `skill-search` | Full-text search across all skills |
| `skill-use-preview` | Preview skill match without executing |
| `skill-execute-guided` | Execute task with skill-guided VACP |

### SkillMatchScore (Multi-Dimensional Scoring)

Each skill candidate is now scored across 5 dimensions:

```csharp
public class SkillMatchScore
{
    public double AppMatch;        // 0–1: process/window name compatibility
    public double TextMatch;       // 0–1: task text vs skill name/trigger
    public double ActionSequenceMatch;  // 0–1: inferred action type vs procedure steps
    public double RiskMatch;       // 0–1: task risk vs skill risk level
    public double RecencyFactor;   // 0–1: logarithmic usage recency weighting
    public double Total;           // weighted sum → 0.0–1.0
    public bool IsUsable;          // hard filters: L0 blocked for high-risk tasks
}
```

### SkillExecutionPolicy (Hard Filters)

Before a skill is considered, hard filters must pass:

```csharp
// L0 skills (no verification) are blocked for:
// - delete / 删除 / remove / 卸载
// - transfer / 转账 / 支付
// - send / 发送 (messaging apps exempt)
// → IsUsable = false if blocked
```

### SkillHint Injection

When a skill scores ≥ 0.7, a `SkillHint` is injected into `VacpRequest`:

```csharp
public class SkillHint
{
    public List<string> SuggestedElements { get; set; }   // element labels to prioritize
    public List<string> SuggestedActionTypes { get; set; }  // type/click/press
    public string PreferredRiskLevel { get; set; } = "L0";
}
```

**Critical V0.8 rule:** SkillHint **guides** VACP (element ranking, action preference), **never bypasses** it. `SkippedBySkill` is **always `false`** in V0.8.

### VacpSkillIntegration

```csharp

```

### VacpPlannerWithSkills (Skill-Guided Pipeline)

```csharp

// V0.7 legacy: Short-circuit on high-confidence skill hit
public async Task<VacpSkillResult> PlanWithSkillsLegacy(VacpRequest request, string? appPattern)
```

| Feature | V0.7 | V0.8 |
