# PeekabooWin V0.9 Release Notes

## V0.9 Multi-App Skill Generalization

**Build:** `dotnet build -c Release` → 0 errors, 0 warnings
**Tag:** `peekaboo-win-v0.9` (commit 56acd77)

## What is V0.9?
Skills learned on one application (Edge Doubao, Notepad) can now be safely transferred to similar applications without dangerous cross-domain contamination.

## What was changed?
### New Core Components

| Component | Description |
|-----------|-------------|
| `WindowSignature` | Fingerprints active window: WindowType + InputMode + RiskDomain + ProcessFamily + AnchorCandidates + OcrHints + Profile back-compat |
| `AppProfile` | Persistent app automation characteristics built from WindowSignature |
| `SkillScope` | Cross-app migration rules: SupportedApps + RequiredAnchors + ForbiddenDomains + MinRiskLevel |
| `SkillScopeValidator` | Pre-injection scope validation |
| `NegativeTransferGuard` | Blocks dangerous transfers even if score >= 0.75: HIGH_RISK_VERB+L0/L1 skill, forbidden domain, external_ai_chat→payment/admin |
| `AnchorMatcher` | Matches VisualAnchor specs against screen OCR results |
| `SkillTransferController` | Full transfer decision pipeline: ScopeValidator → NegativeGuard → AnchorCheck → ScoreWeighting → Decision |
| `VisualAnchor` | Canonical UI anchor types: input_box/send_btn/ok_btn/cancel_btn/close_btn/edit_region |

### Enum Types Added (Models/)
| File | Values |
|------|--------|
| `WindowType.cs` | Edit, WebBrowser, Dialog, SystemSettings, FileExplorer, Unknown |
| `InputMode.cs` | TextInput, Mixed, ButtonClick, Unknown |
| `RiskDomain.cs` | Safe, Dangerous, Payment, Messaging, Admin |

### VisualSkill Fields Added
- `RiskDomain` (string) - skill risk domain for cross-app guard checks
- `ContextAnchors` (List<string>) - anchor labels extracted from task trace

### VacpSkillIntegration Rewritten
- `BuildWindowSignature()` - captures active window state including Profile and AnchorCandidates
- `SearchWithContext()` - searches skills then validates each against SkillScope
- `ClassifyWindow()` helper - maps WindowInfo → window type / input mode / risk domain strings

### CLI: new `skill-search-context` command
```
peekaboo-win skill-search-context --task "输入hello" --window notepad
```
Returns: window fingerprint, AppProfile, anchor candidates, SkillScope-validated search results

## Transfer Decision Matrix

| Situation | Score≥0.75 | Action |
|-----------|-----------|--------|
| Safe transfer (Notepad→Notepad) | Yes | INJECT |
| High-risk verb + L0/L1 skill | Any | BLOCK |
| Forbidden domain transfer | Any | BLOCK |
| Missing required anchors | Any | BLOCK |
| L2 skill on payment app | ≥0.75 | INJECT |
| Low score | <0.50 | BLOCK |
