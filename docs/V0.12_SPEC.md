# PeekabooWin V0.12 — Stability Release

## Version History

| Version | Codename | Focus |
|---------|----------|-------|
| V0.10 | Skill Memory | Visual skill recording, recall, and replay |
| V0.10.5 | Risk Gate | High-risk action gating and negative-transfer blocking |
| V0.11 | Cross-App Transfer | Cross-application text input and dialog confirmation |
| V0.12 | Stability | Async pipeline, timeout/cancel, fallback transparency, OCR error model |

## V0.12 Changes

### 1. Async Pipeline Completion

- `ParseTask` renamed to `ParseTaskAsync`, returning `Task<List<AgentStep>>`
- All `GetAwaiter().GetResult()` calls eliminated from the parse pipeline
- `SearchWithContext` renamed to `SearchWithContextAsync`, propagating async up the call chain
- `VacpSkillIntegration.BuildWindowSignature` now calls `BuildWindowSignatureAsync` via `await`
- Remaining `GetAwaiter().GetResult()` count in `src/`: **0** (excluding InputService Win32 timing)

### 2. Timeout/Cancel Mechanism

- `AgentTaskRequest.TimeoutMs` property added (default: 30000 ms / 30 s)
- `AgentTaskResponse.Cancelled` boolean — indicates the task was cancelled before completion
- `AgentTaskResponse.TimeoutTriggered` boolean — indicates the task exceeded its timeout window
- `CancellationTokenSource.CreateLinkedTokenSource` combines user cancellation with `CancelAfter(TimeoutMs)`
- Timeout propagates through the entire parse → execute pipeline

### 3. Fallback Transparency

New diagnostic fields in `AgentTaskResponse` and `ParseTaskMetadata`:

| Field | Type | Description |
|-------|------|-------------|
| `parser_mode` | `string` | `"regex"` or `"llm"` — which parser produced the result |
| `llm_enabled` | `bool` | Whether LLM parsing was available for this request |
| `fallback_reason` | `string?` | If regex fallback occurred, the reason (e.g. `"llm_timeout"`, `"llm_error"`, `"llm_disabled"`) |
| `llm_error_code` | `string?` | LLM API error code if applicable (e.g. `"rate_limit"`, `"auth_failure"`) |

### 4. OCR Error Model

- `OcrResult.ErrorCode` property added — nullable string for OCR-specific error codes
- `OcrResult.Success` computed property — `true` when `ErrorCode` is null and text content is non-empty
- Enables downstream code to distinguish between "OCR succeeded with empty text" and "OCR failed with error"

### 6. Thread.Sleep → Task.Delay

- `SkillReplayEngine` now uses `Task.Delay` with `CancellationToken` instead of `Thread.Sleep`
- Window focus delay: `Thread.Sleep(300)` → `await Task.Delay(300, cancellationToken)`
- Replay step delay: `Thread.Sleep(200)` → `await Task.Delay(200, cancellationToken)`
- Enables cancellation during replay wait periods
