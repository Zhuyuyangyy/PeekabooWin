# PeekabooWin V0.10 — 自动化路线图

## 目标
基于 V0.9 Multi-App Skill Generalization，继续深化跨应用自动化能力。

## 计划功能

### 1. HTTP API Server (V0.9遗留)
实现 HTTP REST API 端点，供外部 Agent（OpenClaw/Hermes）调用：
```
POST /api/v1/transfer/decide    - 技能迁移决策
POST /api/v1/window/capture     - 窗口截图+OCR
GET  /api/v1/skills/list        - 技能列表
POST /api/v1/skills/inject      - 技能注入
GET  /api/v1/app/profile        - 当前应用Profile
```

### 2. RAG Skill Memory
基于 V0.8 的 `VisualSkillStore`，加入向量检索：
- 使用 embed 模型（如趁手的embedding服务）
- Skill embedding → 向量数据库
- Query 时计算余弦相似度

### 3. Cross-Domain Learning
实现"外部AI对话"应用到其他应用的技能学习：
- 学习模式：AI生成操作 → 人类确认 → 保存为正式Skill
- 隔离机制：external_ai_chat domain 的技能不能直接迁移到 payment/admin

### 4. Skill Versioning
- 技能多版本管理
- 回滚机制
- 技能质量评分

### 5. Real-World Benchmarks
建立15个真实场景测试集：
1. 浏览器表单填写
2. 记事本文本编辑
3. 银行转账（高风险）
4. 文件管理器操作
5. 设置面板导航
6. 对话框确认/取消
7. AI聊天应用操作
8. 表格数据录入
9. 搜索框操作
10. 按钮点击
11. 多步骤工作流
12. 跨窗口数据传输
13. 错误恢复
14. 安全关键操作
15. 管理员操作

### 6. Performance Optimization
- 窗口签名缓存（避免重复计算）
- OCR 结果缓存
- SkillMatchScore 计算优化
